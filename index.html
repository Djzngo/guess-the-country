Guess The Country

Welcome to 'Guess The Country' where to win, you have to enter the correct country genereated.

How to Play

To play the game please head to the 'Game' webpage here where you can then click the 'Start Game' button which will generate a random country for you to guess.

Gameplay

During gameplay each guess enetered will add to a guess counter if incorrect. At a certain number of guesses you will unlock the following:

  1. 10 guesses - Reveals the region i.e Europe, Asia, Africa
  2. 15 Guesses - Reveals the currency i.e EUR, CZK, RUB
  3. 20 Guesses - First letter of the country is revealed

About

This game uses the 'Rest Countries' API to request a dataset of countries with additional information such as currency, region, common name, and much more. I extract the information needed from the object requested, and use it for this game to work. There are some features I would like to implement in the future such as a post statistics, daily tracking, distance from current guess unable to create something like this
